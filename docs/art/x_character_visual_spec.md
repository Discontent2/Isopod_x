# X Character Visual Specification

This document records the visual identity established during sprite development for the `isopod_x` protagonist, X.

## Core Silhouette

X is an anthropomorphic isopod action hero with a broad, compact, armored silhouette. The design should read immediately at small sprite scale.

Key features:

- Layered, segmented isopod shell armor.
- Silver-gray / bone-gray shell palette with darker recesses.
- Large dark expressive eyes with warm highlights.
- Two long segmented antennae.
- Two tusk-like / mandible-like mouth appendages.
- Clawed hands.
- Rugged dark wrist wraps carrying red `X` accents.
- Chunky heavy boots with thick soles and visible buckles/straps.
- Strong action-hero stance rather than a naturalistic crawling-isopod body plan.

## Style Language

- Retro 16-bit-inspired pixel art.
- Hard pixel edges.
- Strong contrast between shell plates and deep joints/shadows.
- Details should remain legible when reduced to about 64x64.
- Avoid micro-detail that collapses into noise at gameplay scale.
- Keep shell plate count, proportions, antenna placement, mandibles, boots, and wrist-wrap language consistent between assets.

## Facing and Pose

Default gameplay art faces right. Left-facing gameplay should normally be produced by horizontal mirroring in-engine.

For ranged-combat poses, X uses a classic side-scroller blaster stance:

- firing arm extended forward toward the right,
- opposite arm pulled back for balance,
- front knee bent,
- rear leg braced,
- compact, readable silhouette suitable for rapid animation.

## Production Consistency

Any future sprite, animation, weapon-holding pose, or promotional pixel-art asset should treat the most recently approved X sprite as the canonical sprite reference. Concept art may inform materials and anatomy, but should not silently redesign the gameplay character.
