# Reference Art

These images are visual design references for `isopod_x`, not runtime sprite sheets.

- `x_warrior_sprite.png` — X standalone character reference.
- `x_with_peashooter.png` — X holding the earlier alien Peashooter concept.
- `living_peashooter_sidearm.png` — current living isopod Peashooter concept.
- `x_firing_living_peashooter.png` — X firing the living Peashooter in the intended side-scroller blaster stance.
- `bio_essence_carbine_evolution_sheet.png` — visual exploration of Essence-powered weapon attachments, morphing, grenades, and mines.
- `isopod_x_mignola_style_reference.png` — compact preview of the Mignola-inspired graphic-novel style study for X and the Living Peashooter.
- `isopod_x_mignola_style_reference.md` — YAML-frontmatter metadata, generation details, prompt, visual analysis, canonical boundaries, and art-direction takeaways for that style study.

These are compact repository previews. Production-ready sprite sheets must follow the contracts in `docs/art/` and should live under `assets/` when finalized.
