# Series 1 Toy and UI Reference Notes

This document records the current visual direction established during Series 1 toy and game-interface exploration.

## Isopod-X toy interpretation

X uses a compact vintage micro-beast action-figure silhouette rather than a modern superhero or ninja-turtle-like body plan.

Key traits:

- broad, squat proportions
- oversized segmented isopod head/shell
- large expressive eyes beneath shell brows
- two curved mandible/tusk forms
- long segmented antennae
- silver-gray shell armor
- blue chest armor and oversized boots
- purple limb sections
- red X emblems and belt accents
- large simple claw hands
- chunky molded details rather than dense modern sci-fi greebling

The working nominal toy scale is approximately 2 inches / 50.8 mm, with proportion guidance documented separately in `toy_scale_proportions.md`.

## Needle Strike printable-parts reference

Needle Strike is the Air-faction assassin-bug character.

For the current PrintPal-oriented reference:

- wings are omitted for now because they would be fragile and difficult for the intended FDM workflow
- the torso uses **shoulder sockets**, not protruding shoulder balls
- each detached arm carries a robust ball peg intended to mate with the torso socket
- arm geometry should remain thick and toy-like enough for printing
- the assassin-bug rostrum, antennae, narrow head, and armor color blocking provide the main silhouette identity

## Series 1 stage-select screen

The stage-select layout uses eight boss portraits arranged around Isopod-X in the center.

Bosses:

Pincer Punk, Razor Prayer, Spectrum Smasher, Velvet Vengeance, Triops Tyrant, Jawstorm, War Wētā, Siphon Strike.

Each boss should have clearly distinct armor colors while still sharing the same vintage micro-beast toy design language. X remains silver/blue/purple/red and acts as the visual anchor.

## Title screen

The current title-screen direction is an original 8-bit-era action-game composition informed by late-NES title-screen structure:

- large ISOPOD_X logo near the top
- toy-inspired X featured prominently
- dark alien / shell-world environment
- simple menu with `GAME START` as the primary selection
- high-contrast pixel-art presentation

The generated screen is a concept reference only. Any copyright line, menu option, logo detail, or year shown in the concept art is provisional until implemented in-game.

## Reference-art status

All images associated with this document are **visual references**, not runtime assets. Production UI and sprites must be rebuilt to the project's actual pixel-grid, palette, resolution, animation, and gameplay requirements.
