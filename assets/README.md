# Runtime Assets

This directory is reserved for files that the game loads at runtime.

Planned organization:

- `assets/sprites/` — production character, enemy, projectile, and object sprites/sheets.
- `assets/tiles/` — production tilesets and level graphics.
- `assets/ui/` — HUD and menu graphics.
- `assets/vfx/` — runtime visual-effects artwork.
- `assets/audio/` — music and sound effects.

Concept art and generated visual references belong in `docs/reference_art/`, not here. Production sprite sheets must conform to the technical contracts documented in `docs/art/`.
